# iPhone
## How to find your phone's model and serial number (and other info)
**Tap the _Settings_ icon**

![iPhone Settings](images/iphone_settings.png){: width=100 }

---

**Tap _General_**

![iPhone About](images/iphone_general.png){: width=375 }

---

**Tap _About_**

![iPhone About](images/iphone_about.png){: width=375 }

---

**Phone Information Screen**

You should see information about your phone listed like:

- Model Name
- Model Number
- Serial Number
- etc.

![iPhone Information](images/iphone_info.png){: width=375 }
